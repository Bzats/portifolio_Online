 🌐 Meu Portfólio Online

Bem-vindo ao repositório do meu Portfólio Online! Este projeto foi desenvolvido para apresentar minhas habilidades, experiências e projetos recentes, utilizando as tecnologias mais modernas do ecossistema front-end.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:

* **[React](https://react.dev/)** - Biblioteca JavaScript para construção de interfaces.
* **[TypeScript](https://www.typescriptlang.org/)** - Superset do JavaScript que adiciona tipagem estática e segurança.
* **[Vite](https://vitejs.dev/)** - Ferramenta de build incrivelmente rápida para projetos web modernos.
* **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS utilitário para estilização responsiva e ágil.
* **[shadcn/ui](https://ui.shadcn.com/)** - Componentes de interface reutilizáveis, acessíveis e customizáveis.
* **[Vitest](https://vitest.dev/)** & **[Playwright](https://playwright.dev/)** - Ferramentas de ponta para testes unitários e testes End-to-End (E2E).

⚙️ Pré-requisitos

Antes de iniciar, certifique-se de ter as seguintes ferramentas instaladas em sua máquina:

* [Git](https://git-scm.com/)
* [Node.js](https://nodejs.org/) (versão 18 ou superior)
* [Bun](https://bun.sh/) ou npm (O projeto contém o arquivo `bun.lock`, sendo o Bun o gerenciador de pacotes recomendado para maior velocidade).

🛠️ Passo a Passo: Como rodar localmente

Siga as instruções abaixo para clonar e rodar o projeto no seu ambiente de desenvolvimento.

### 1. Clone o repositório

Abra o seu terminal e execute o seguinte comando:

```bash
git clone [https://github.com/Bzats/portifolio_Online.git](https://github.com/Bzats/portifolio_Online.git)

2. Navegue até o diretório do projeto
Bash
cd portifolio_Online
3. Instale as dependências
Você pode optar por utilizar o Bun ou o npm:

Opção A - Usando Bun (Recomendado):

Bash
bun install
Opção B - Usando npm:

Bash
npm install
4. Inicie o servidor de desenvolvimento
Para rodar o projeto e ver as alterações em tempo real, execute:

Usando Bun:

Bash
bun run dev
Usando npm:

Bash
npm run dev
O terminal exibirá uma URL (geralmente http://localhost:8080 ou http://localhost:5173). Clique no link ou abra no seu navegador para visualizar o portfólio!

📦 Scripts Disponíveis
No diretório do projeto, você pode executar diversos comandos (utilizando npm run <comando> ou bun run <comando>):

dev: Inicia o servidor local de desenvolvimento.

build: Compila o projeto de TypeScript para JavaScript, otimizando os arquivos para produção na pasta dist.

preview: Inicia um servidor local servindo os arquivos de produção recém-compilados (ótimo para testar o build antes do deploy).

📁 Estrutura do Projeto
/src: Código-fonte principal (Páginas, Componentes React, Estilos e Hooks).

/public: Arquivos estáticos globais (imagens, ícones e fontes) que não são processados pelo Vite.

components.json: Configurações da biblioteca de componentes shadcn/ui.

tailwind.config.ts: Definições globais de design system, cores e breakpoints da aplicação.
